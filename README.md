## ✨ Features

### 🔧 Core Functionality
- **Responsive Design**: Fully responsive layout that works on all devices
- **Complex Navigation**: Multi-level dropdown menus with smooth animations
- **Interactive Components**: Carousels, accordions, and interactive elements
- **Bootstrap Integration**: Custom Bootstrap components with personal styling
- **Mobile-First Approach**: Optimized for mobile devices

### 📱 Sections Implemented
- ✅ Complete navigation bar with dropdown menus
- ✅ Hero section with app download CTA
- ✅ Recharge & bill payments section
- ✅ Ticket booking interface
- ✅ Payment instruments showcase
- ✅ Financial services section
- ✅ Business tools display
- ✅ Investment opportunities carousel
- ✅ Comprehensive footer with accordions

## 🛠 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: Bootstrap 5.3.2
- **Icons**: Iconify, Font Awesome
- **Carousel**: Owl Carousel 2
- **Responsive**: Media Queries, Flexbox, Grid
